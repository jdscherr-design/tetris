# Tetris

A browser Tetris written in plain HTML, CSS and JavaScript, with nothing to build or install.

## Play

Open `index.html`, or visit the GitHub Pages site for this repository.

| Key | Action |
| --- | --- |
| ← → | Move |
| ↓ | Soft drop |
| Space | Hard drop |
| ↑ / X | Rotate right |
| Z | Rotate left |
| C / Shift | Hold |
| P / Esc | Pause |

Phones and tablets get on-screen buttons.

## Deploy

GitHub Pages serves the root of the `main` branch, so pushing to `main` publishes the game.
